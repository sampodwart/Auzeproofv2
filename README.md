# AuzEnergyz Proof Checker

Educational tool for identifying *risk indicators* in oil & gas Soft Corporate Offers (SCOs).

✅ This project does **not** prove legitimacy.  
✅ It does **not** accuse or label scams.  
✅ It helps people know **what to verify next**.

---

## Mobile use (no coding)

### How to check an SCO using AI (recommended)
1) Copy the SCO text (email/PDF text).
2) Paste it into ChatGPT (or any AI).
3) Paste this prompt above it:

**AuzEnergyz Prompt**
